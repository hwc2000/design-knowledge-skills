# 복제: 복사본을 어떻게 맞추나

## 먼저 물을 것 (비판적 질문)

1. **왜 복제하나?** 가용성 / 읽기 확장 / 지역별 지연. 목적에 따라 방식이 달라진다.
2. **쓰기는 누가 받나?** 한 곳(primary) / 아무 곳(리더리스) / 모두가 같은 순서로 실행(상태 기계 복제).
3. **동기 vs 비동기:** 리더가 죽을 때 "성공"이라고 답한 쓰기를 잃어도 되나?
4. **N·W·R 을 몇으로?** 노드 하나·둘이 죽으면 읽기와 쓰기가 계속 되나? **노드가 2대면 과반이 없다.** 둘이 끊기면 누가 진짜 primary 인지 정할 수 없다 → 3대(또는 투표만 하는 세 번째)나 수동 페일오버.
5. **지금 쓰는 DB 가 복제를 지원하나?** 지원하지 않으면(예: SQLite) 복제 도구를 붙일지, 복제가 되는 DB 로 옮길지가 먼저다. 제품 상태는 검색해서 날짜와 함께 말한다.
6. **뒤처진 복사본은 어떻게 따라잡나?** 읽을 때 고치기(read repair) / 주기적 비교(anti-entropy) / 대신 받아 두기(hinted handoff).
7. **페일오버는 누가 결정하나? 옛 primary 가 돌아오면?** → design-failure 의 펜싱.
8. **'성공'은 언제 알리고, 읽기는 어디까지 보여 주나?** 충분한 사본(보통 과반)이 저장한 뒤에 확정·성공을 알린다. 아직 확정되지 않은 값은 읽기에 내보내지 않는다. 내보내면 장애 뒤 그 값이 사라져 사용자가 '봤던 게 없어지는' 일을 겪는다.
9. **동시에 몇 대가 죽어도 버텨야 하나(f)?** 과반 방식이면 2f+1대가 필요하다(짝수는 이득 없음). 늘릴수록 튼튼하지만 확정은 과반 중 가장 느린 응답만큼 늦어진다.

## 선택지 한눈에

| 방식 | 쓰기 | 강점 | 약점 |
|---|---|---|---|
| Primary-backup (원격 쓰기) | primary 한 곳 | 단순, 순서 명확 | primary 병목, 페일오버 필요 |
| Primary-backup (지역 쓰기) | primary 를 옮겨 옴 | 한 곳에서 연속 쓰기 빠름 | primary 이동 비용 |
| Active replication | 모두 실행 | 즉시 대체 가능 | 전체 순서·결정적 연산 필요 |
| 리더-팔로워 로그 복제 (예: Raft, Kafka) | 리더 한 곳, 로그 순서대로 | 순서 명확, 일부 사본만 확인하면 확정 | 리더가 쓰기 병목, 확정 경계 관리와 리더 교체 때 미확정 꼬리 정리 필요 |
| Quorum (리더리스) | W 개에 씀 | 노드 장애에 강함, 조절 가능 | 충돌 처리, 일관성 조건 복잡 |

## 흔한 함정

- 복제는 백업이 아니다. 잘못된 삭제도 그대로 복제된다 (강의 밖).
- 비동기 복제 + 자동 페일오버는 확인된 쓰기를 잃을 수 있다.
- 읽기를 복사본으로 돌리면 "방금 쓴 게 안 보이는" 문제가 생긴다 → design-consistency.
- 느린 사본을 확정 계산에서 빼 주는 방식은, 최소 사본 수를 강제하지 않으면 결국 한 대만으로 확정하게 된다 (예: Kafka ISR + min.insync.replicas).
- 구성원 수를 바꾸는 것도 하나의 결정이라 과반 동의가 필요하다. 과반을 잃은 뒤에는 줄일 수도 없으니 미리 줄인다.

## 쓰는 규칙

- references 는 내 강의 정리다. 근거로 인용하되 정답으로 쓰지 않는다. 실무 상황과 맞지 않으면 그렇다고 말한다.
- 특정 제품·버전(Kafka, etcd, Redis 등)을 고르는 순간에만 최신 상황을 검색하고 날짜를 붙인다. 확인 못 하면 모른다고 말한다.
- references 는 통째로 읽지 말고 아래 목록에서 파일을 골라 Grep 으로 주제(`### 제목`)만 찾아 읽는다.
- 질문이 이 스킬 범위를 넘으면 `references/관련-주제.md` 를 본다. 거기 없어도 걸치는 것 같으면 다른 design-* 스킬의 references 도 직접 Grep 한다. 링크는 지름길일 뿐 전부가 아니다.
- 같은 개념이 여러 과목 폴더에 있으면 둘 다 본다. 내용이 다르면 출처와 함께 둘 다 보여 주고 어떤 조건에서 무엇이 맞는지 말한다. 몰래 하나를 고르지 않는다.
- 강의에 없는 일반 지식을 덧붙일 땐 "(강의 밖)" 이라고 표시한다.
